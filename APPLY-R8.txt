HOW TO APPLY (2 minutes)
------------------------
1. Unzip this file.
2. Copy EVERYTHING inside it over your project folder. "Replace" when asked.
   → Do NOT delete your .env or db/ folder — they're not in this zip.
3. In the terminal, inside your project folder:

     npm install
     npx prisma generate

4. Start it:

     npm run dev

5. Open http://localhost:3000 and hard-refresh (Ctrl+Shift+R).

No database migration, no SQL, nothing manual — this release changed NO
database schema.


DEPLOYING (Render — unchanged flow)
-----------------------------------
     git add -A
     git commit -m "R8: landing gallery fix, builder wizard + welcome back, modern template multipage fix"
     git push

Render detects the commit and auto-deploys. Nothing to click.


IF SOMETHING LOOKS OFF
----------------------
- 404 or stale page? Hard-refresh (Ctrl+Shift+R), or restart npm run dev.
- "Module not found"? npm install again inside the project folder.
