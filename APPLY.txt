HOW TO APPLY (2 minutes)
------------------------
1. Unzip this file.
2. Copy EVERYTHING inside it over your project folder (the same folder
   you push to GitHub from). Choose "Replace" when asked.
   → Do NOT delete your .env file or your db/ folder. They are not in
     this zip, so copying over them will not touch them.
3. In the terminal, inside your project folder:

     npm install
     npx prisma generate

4. Start it:

     npm run dev

5. Open http://localhost:3000 and hard-refresh the browser
   (Ctrl+Shift+R) so old cached scripts are dropped.

That's all. No database migration, no SQL, nothing manual — this release
changed NO database schema, so your existing data keeps working as-is.

IF SOMETHING LOOKS OFF
----------------------
- 404 or old page after applying? You probably skipped the
  Ctrl+Shift+R hard refresh, or npm install didn't finish.
- "Module not found" on npm run dev? Run npm install again inside the
  folder that contains package.json.
- Styles show but look unstyled? Restart npm run dev once.
